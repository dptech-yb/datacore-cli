  <section class="dc-section dc-core-section">
    <div class="dc-section-heading">
      <p class="dc-eyebrow">WHAT YOU INSTALL</p>
      <h2>一个安装包，三层调用能力。</h2>
      <p>CLI 负责执行，Skills 告诉 Agent 如何正确使用，结构化输出让脚本稳定理解结果。</p>
    </div>
    <div class="dc-core-grid" aria-label="DataCore CLI 组成">
      <article>
        <span class="dc-node-index">01</span>
        <div><strong>CLI</strong><small>面向终端与自动化脚本的稳定命令入口。</small><code>{'datacore --help'}</code></div>
      </article>
      <article>
        <span class="dc-node-index">02</span>
        <div><strong>Agent Skills</strong><small>安装时自动同步，约束确认、重试和恢复逻辑。</small><code>{'datacore skills list'}</code></div>
      </article>
      <article>
        <span class="dc-node-index">03</span>
        <div><strong>JSON Contract</strong><small>统一成功、错误、产物和下一步字段。</small><code>{'datacore --json …'}</code></div>
      </article>
    </div>
  </section>
