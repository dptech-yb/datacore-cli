  <section class="dc-section dc-proof-section">
    <div class="dc-section-heading compact">
      <p class="dc-eyebrow">BUILT FOR REAL WORK</p>
      <h2>不是 API 的薄包装，而是可执行的业务契约。</h2>
    </div>
    <div class="dc-proof-grid">
      <article>
        <span>01 / IDENTITY</span>
        <h3>沿用当前平台身份</h3>
        <p>密码、飞书或 Bohrium 登录最终都绑定到同一个 DataCore 用户。项目、实验与操作权限继续由平台判断。</p>
      </article>
      <article>
        <span>02 / CONTROL</span>
        <h3>写操作必须确认</h3>
        <p>查询可直接执行；上传、训练和开启下一轮先冻结目标与参数，再由用户明确确认，避免 Agent 擅自改变任务。</p>
      </article>
      <article>
        <span>03 / RECOVERY</span>
        <h3>云端任务不会因终端关闭而丢失</h3>
        <p>推荐与五折训练持久化运行状态。本地中断后重新查询即可继续，失败折也能单独恢复。</p>
      </article>
    </div>
  </section>
